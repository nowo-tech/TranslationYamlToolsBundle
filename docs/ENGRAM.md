# Engram (MCP)

This repository ships a baseline [Model Context Protocol](https://modelcontextprotocol.io/) configuration for the **Engram** server.

## Cursor / IDE

- File: `.cursor/mcp.json`
- Server: `engram` with command `engram` and arguments `["mcp"]`

Install the `engram` CLI on your machine if you want assistants to use this integration. The bundle works without MCP; this file is optional tooling for maintainers.
